# Диаграммы классов

Все диаграммы строит из кода Go генератор `src/classes.py`. Уровней подробности три — под разные носители.

| Уровень | Файлы | Куда | Что показано |
|---|---|---|---|
| Обзорный | `overview`, `overview-fragment` | Презентация, начало раздела 2 | 13 ключевых сущностей всех сервисов: имена, связи, кратности. Фрагмент — узел, экземпляр и сборка с полями |
| Рабочий | `text/*-entities`, `text/service-*` | Раздел 2 записки, книжный А4 | Сущности сервиса с полями (до восьми), без методов и перечислений; сервис с операциями и именами его зависимостей |
| Полный | `*.puml` в корне каталога | Приложение, листы А3 | Сущности, перечисления, сервисы и интерфейсы с полями и методами |

Зависимости всех сервисов сведены в таблицу `text/dependencies.md` — она заменяет в тексте листы сервисов с пересекающимися стрелками.

Пересборка:

```bash
cd docs/classes
python3 src/classes.py
PLANTUML_LIMIT_SIZE=16384 plantuml -tpng -tsvg *.puml text/*.puml
```
