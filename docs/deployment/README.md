# Диаграмма развёртывания

UML-диаграмма развёртывания системы: `deployment.drawio`, экспорт — `deployment.png` и `deployment.svg`.

Диаграмма собирается генератором `src/deployment.py` с явными координатами, поэтому правки вносятся в него, а не в `.drawio`:

```bash
python3 src/deployment.py deployment.drawio
drawio -x -f png -s 2 -o deployment.png deployment.drawio --no-sandbox
drawio -x -f svg -o deployment.svg deployment.drawio --no-sandbox
```

Состав сверен с `deployments/docker-compose.*.yml`, конфигурацией Nginx (`src/frontend/nginx.conf`) и сервисами в `src/`:

- **Сервер платформы.**
  - Nginx отдаёт SPA, проксирует `/api` в API-шлюз, а `/game-proxy` во входной прокси. Игры и медиа он раздаёт с диска, а если файла нет — из SeaweedFS.
  - Четыре gRPC-сервиса: модерация вызывает управление проектами и оркестрацию, управление проектами — модерацию и агент развёртывания веб-игр.
  - Хранилища: PostgreSQL, Valkey, SeaweedFS (S3).
- **Вычислительный узел.**
  - Агент узла регистрируется у оркестратора и шлёт сигналы присутствия на порт `:50052`, а оркестратор управляет узлом и получает журналы через порт `:44044`.
  - На узле работают экземпляры игровых серверов и сервисы данных игры с резервными копиями.
- **Подключение игрока.** Через входной прокси платформы или напрямую по домену узла.
- **Смежные системы.** Почтовый сервер (SMTP) для сервиса аутентификации и сервис аналитики площадки для сервиса управления проектами.
